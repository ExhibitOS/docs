# 전시 template의 제출과 재사용 권리

[template 제출 양식](../templates/exhibition-template.md)에 source revision/hash와 구성 파일, 저자/license/credit, 변경, 포함 asset·font·audio 각각의 출처/허용 범위를 기록합니다. 외부 runtime URL·secret·private CMS/계정 binding·원본 Capture 자료를 template에 넣지 않습니다. 합성 또는 재배포 허용 자료를 사용하고 공개 schema와 현재 import 한도를 확인합니다.

template의 방/배치/설명문/실행 script와 작품/음성/폰트/브랜드는 별개 권리입니다. 이 docs 저장소의 설명문은 CC-BY-4.0, 실행 예제는 Apache-2.0입니다. 다른 제품/template에는 그 저장소의 LICENSE·per-file 고지를 적용합니다. 이 페이지가 모든 template에 새 license를 부여하지 않습니다. 프로젝트 원문 license-map과 법률 원문을 바꾸지 않습니다.

유지관리자는 파일 inventory/hash, 단위·참조·현재 rights, artifact export/재배포 가능 여부와 attribution 누락을 검토합니다. OEX 형식 통과는 모든 embedded prose/media의 개인정보·저작권 검사 완료가 아닙니다. script가 실행 가능하면 기존 허용된 공개 계약을 확인하고 임의 endpoint/명령을 실행시키지 않습니다. 번역 template은 원문 추적과 인간 review도 남깁니다.

ExhibitOS 명칭/로고를 이용한 공식 인증·상표 허락, 후원 표시·공식 hosted 이용 약정은 소유자의 별도 결정입니다. 코드 license만으로 허락됐다고 표시하거나 아직 결정되지 않은 brand 정책을 확정 문구로 쓰지 않습니다. 기존 [license 연구 제안](license-policy-proposal.md)은 연구 기록이며 적용 LICENSE를 대체하지 않습니다.
