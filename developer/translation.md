# 원문을 추적하는 번역 기여

[번역 검토 양식](../templates/translation-review.md)에 원문 repository/path와 exact commit, 원문 UTF-8 SHA-256, source/target language, 번역자·검토자와 수정 시각을 적습니다. 개인 이메일 대신 허용한 표시 이름을 사용할 수 있습니다. 원문 URL과 저자/license 고지를 유지하고 변경/번역임을 표시합니다.

원문과 번역을 별도 파일/필드로 보존합니다. locale, 치수/단위, 권리 유효 기간, 독립 display/export 의미와 오류 안내를 대조합니다. 기계 번역 또는 AI 제안은 도구·버전·제안임을 표시하고 인간이 직접 수락/거절합니다. 외부 제공자에 비공개 원문을 보내려면 실제 권한·명시적 전송 동의가 먼저 필요합니다. 현재 제품의 외부 consent 기록은 실제 provider 호출의 증거가 아닙니다.

원문 revision/hash가 바뀌면 번역을 낡은 것으로 표시하고 차이를 다시 검토합니다. 파일이 존재하거나 AI가 작성했다는 이유로 최신/승인된 번역으로 취급하지 않습니다. CMS 검토 translation은 원문과 별도로 보존되며 자동으로 공개 전시에 실리지 않습니다. 전시의 기존 reviewed translation flow에서 curator/owner가 직접 연결·검토합니다.

문서 번역은 원문 CC-BY 조건과 attribution을 유지합니다. 작품 설명/작가 원문·외부 인용은 각 권리자의 조건을 따르며 문서 라이선스로 자동 재허락하지 않습니다. 저장소의 공개 여부나 공식 번역 인증은 유지관리자 결정입니다.
