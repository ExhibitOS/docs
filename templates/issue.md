# Issue 제출 양식

- 제품/저장소와 exact revision:
- OS·브라우저·제품 버전:
- 기존 Issue/관련 공개 계약:
- 합성 자료로 재현하는 단계:
- 기대한 결과:
- 실제 결과/안전한 오류 코드:
- 실행한 검사와 실패/미실행:
- 사용자 영향/접근성 막힘:
- 제안 범위:

원본 작품·사진·개인정보·token·cookie·key·DB URL·raw log는 제외합니다. 보안 문제는 공개 Issue 대신 비공개 보고 경로를 확인합니다. 외부 파일을 넣으면 source URL/license/재배포 권리를 기록합니다. 이 양식은 GitHub 자동 Issue form/label가 설치됐다는 뜻이 아닙니다.
