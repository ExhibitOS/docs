# 번역 검토 기록

- 원문 repository/path/URL:
- exact source commit / UTF-8 SHA-256:
- source locale / target locale:
- 번역 파일/field와 hash:
- 번역자 표시 이름 / 검토자:
- human 또는 AI-assisted 도구·버전:
- 권리/license/attribution와 변경 고지:
- 단위·권리·오류 안내 대조 결과:
- 원문 변화 여부와 재검토:
- 결정: accepted / rejected / 수정 필요
- 검토 시각 및 미검증 범위:

원문은 덮어쓰지 않습니다. accepted 문서 번역과 CMS/전시 공개 승인은 별개입니다. private 원문 전송 동의·actual 실행은 따로 기록하고 secret을 포함하지 않습니다.
