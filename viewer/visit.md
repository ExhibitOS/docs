# 전시 관람 안내

이 안내는 [지원 범위에 표시한 개발 snapshot](../status.md)의 조작입니다. 공개 전시 URL을 연 뒤 목록으로 시작하며, 전시가 철회됐거나 현재 권리가 만료됐으면 접근할 수 없습니다.

## 목록에서 읽기

작품 제목·설명·치수·권리·번역과 등록된 음성 대본을 3D 이동 없이 읽습니다. Tab으로 이동하고 Enter 또는 Space로 버튼을 실행합니다. 상세 안내는 닫기 버튼 또는 Esc로 닫으며 실행한 버튼으로 초점이 돌아옵니다. 미기록 정보는 새로 추정하지 않습니다.

## 3D와 걷기

1. `3D 관람 시작`을 선택합니다. 걷기와 소리는 별도로 시작합니다.
2. `걷기 시작`을 누르고 W/A/S/D 또는 위·아래 화살표로 이동합니다. 좌우 화살표로 시점을 돌립니다.
3. 마우스 회전은 `마우스 시점 잡기`를 직접 선택합니다. 캡처가 허용되지 않으면 키보드 또는 정지 관람을 사용합니다.
4. Esc, 창 초점 상실이나 숨겨진 탭은 보행을 멈춥니다. 돌아온 뒤 `걷기 재개`를 선택하면 현재 위치를 유지합니다.
5. 위치를 복구하려면 `안전한 시작 위치로`, 보행을 끝내려면 `정지 관람으로 전환`을 선택합니다.

`글·목록 관람으로 돌아가기`는 3D와 소리를 종료하고 입구 버튼으로 초점을 돌립니다. 움직임 줄이기와 고대비 설정을 사용할 수 있습니다. 터치 에뮬레이션 통과는 실제 모바일 지원 검증과 다릅니다.

## 소리와 오프닝

대본은 소리를 켜지 않아도 읽을 수 있습니다. 실제 음성 재생은 3D 관람 후 작품 상세의 음성 버튼으로 선택합니다. 혼자 관람이 기본이며 오프닝 참여, 채팅, 듣기, 마이크와 가이드 따라가기는 각각 직접 선택합니다. 참여만으로 마이크 전송에 동의한 것이 아닙니다. 오프닝에서 나간 뒤 마이크가 자동 재개되지 않습니다.

새 오프닝·큐레이션 조작의 실물 VoiceOver 검사, 물리 모바일·GPU·실제 장거리 음성 연결은 미완료입니다. 전체 WCAG 인증이나 모든 네트워크 지원을 뜻하지 않습니다. 자세한 조작·동의·지원 제한은 [공개 소스 색인](../status.md)을 확인하세요.
