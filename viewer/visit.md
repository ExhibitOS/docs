# 전시 주소에서 감상하기

**목표:** 전시에 입장해 작품을 선택하고 설명·모델을 감상한 뒤 원래 전시로 돌아옵니다.

**준비:** 주최자가 보낸 유효한 전시 주소와 브라우저가 필요합니다. 일반 공개 관람에는 제작 앱이나 제작자 계정이 필요하지 않습니다. 비공개 전시의 인증·접근 권한은 유지됩니다.

홈페이지의 전시 데모는 Viewer 관람으로 연결됩니다. Studio 편집 데모나 정식 앱 다운로드를 제공하는 링크로 해석하지 마세요. 공개 데모와 개발 중인 표지·작품 선명도·연속 감상 수정은 [현재 제공 상태](../status.md)에서 구분합니다. 새 표지 전환이 보이지 않더라도 미공개 개발 동작을 기대해 다시 설치할 필요는 없습니다.

## 관람 시작

1. 전시 주소를 열고 제목·소개를 확인한 뒤 **관람 시작**을 선택합니다.
2. 보이는 작품을 클릭·탭하거나 **작품 목록**의 **작품 상세 보기**를 선택합니다.
3. 제목·작가·설명을 읽고 제공되는 회전·확대로 작품을 살펴봅니다.
4. **전시로 돌아가기** 또는 Esc를 선택합니다. 이전 관람 위치와 작품 선택 초점에서 이어서 볼 수 있습니다.

**확인:** 다른 작품을 선택해 감상할 수 있으면 기본 관람이 연결된 것입니다. 공간 이동이 어려우면 글·목록 관람으로 볼 수 있습니다. 작품 정보가 없으면 추정해 채우지 않습니다.

## 이동과 소리는 선택 사항

- **걷기 시작** 이후 컴퓨터에서 방향키·W/A/S/D, 스마트폰에서 제공되는 터치 조작을 사용합니다. **이동 방법·설정**에서 조작법·속도·눈높이를 확인합니다.
- **마우스 시점 잡기**는 직접 선택합니다. Esc·창 전환·다른 입력 선택은 보행을 멈춥니다. **걷기 일시 정지**, **걷기 재개**, **정지 관람으로 전환**, **안전한 시작 위치로**를 사용할 수 있습니다.
- **소리 켜기**를 선택해야 소리를 준비합니다. 소리 끄기·음량·정지는 찾기 쉬운 곳에 유지하며 대본은 무음으로 읽습니다. 기본 관람에 마이크·카메라 권한은 필요하지 않습니다.
- 선택적 함께 관람·오프닝 등은 그 기능을 사용할 때만 연결·동의를 확인합니다. 기본 정적 관람은 동적 연결과 독립적입니다. 미구현 기능이나 장기 보류 기능의 지원을 뜻하지 않습니다.

## 불러오지 못했을 때

| 증상 | 확인과 안전한 다음 행동 |
| --- | --- |
| 전시 준비 실패 | **다시 시도**를 선택하고 연결을 확인합니다. 무한 대기 대신 오류 안내를 확인하세요. |
| 일부 작품·3D만 실패 | 작품 목록으로 감상하거나 **실패한 작품 다시 시도**, **3D 다시 시작**을 사용합니다. |
| 동적 연결 실패 | 해당 기능의 연결 재확인을 사용합니다. 정적 전시는 계속 관람할 수 있습니다. |
| 소리 차단 | 직접 소리를 켜고 브라우저·기기의 음소거를 확인합니다. 대본으로도 감상할 수 있습니다. |
| 전시 철회·권리 만료 | 주최자에게 현재 유효한 주소를 문의합니다. 캐시나 다른 경로로 접근 권한을 우회하지 않습니다. |

## 접근성과 검증 범위

Tab과 Enter/Space로 조작하고 글·목록 보기·작품 설명·대본을 활용합니다. **글·목록 관람으로 돌아가기**는 3D·소리를 종료합니다. 움직임 줄이기와 높은 대비는 관람 설정에서 바꿀 수 있습니다.

Safari·Chrome을 대상으로 하며 공식 검증 환경은 macOS·iOS입니다. 현재 실제 검사 범위는 [지원 기록](../status.md)과 제품 버전을 확인하세요. 합성 Chromium·터치 에뮬레이션 통과를 실제 Safari·iPhone·VoiceOver 또는 모든 전시의 접근성 인증으로 확대하지 않습니다.
